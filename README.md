# Cheape Deal

Self-hosted dropshipping **order-to-delivery automation** with its own dashboard. Free and open-source stack: FastAPI + Postgres + n8n + Caddy, runs 24x7 on a VPS with Docker.

A customer pays in your WooCommerce store, and Cheape Deal:

1. saves the order (once, even if the webhook fires twice),
2. checks stock, margin, daily cap and your approval rule,
3. places it with CJ Dropshipping (or holds it for you),
4. syncs tracking back to the store and tells the customer once per change,
5. keeps stock and prices in line with the supplier and hides anything that would sell at a loss,
6. alerts you on Telegram when something needs a human.

It does **not** find products, run ads, or bring customers. See "What is not automated".

```
Customer -> WooCommerce --webhook--> Cheape Deal API <--> Postgres
                                          ^    |
                n8n (schedules) ----------+    +--> CJ Dropshipping API
                                          |    +--> WooCommerce REST (notes, status, price, visibility)
                      Dashboard (browser) +    +--> Telegram alerts
```

**Division of labour.** The API holds every rule (idempotency, margin guard, retries, state machine) so it is unit-tested. n8n is the scheduler and the error handler: six small workflows that call `/internal/jobs/*` on a timer.

## Safety model (read this once)

- **DRY-RUN is on by default.** Orders go through every check but nothing is sent to the supplier until you press "Go live" in Settings.
- **Kill switch** on every page. It stops supplier orders, tracking and stock sync at once.
- **Never twice.** A unique store order ID, an atomic lock per order, and a recorded "attempt" before every supplier call. If the supplier call times out and we cannot tell whether it went through, the order stops and asks you. It is never blindly re-sent.
- **Never at a loss.** Orders under the minimum margin are blocked. Products whose margin falls under it are hidden in the store automatically.
- **You approve big orders** (threshold in Settings). Refunds and disputes are never automated.
- Secrets live only in `.env`. Store webhooks are verified by signature. Login is rate-limited, forms are CSRF-protected, `/internal/*` needs a key and is blocked at the public proxy.

## What is not automated

Product research, ads and traffic, refunds and disputes, supplier quality, and customer support replies. A store with no traffic gets no orders; your real cost is advertising.

## Layout

```
api/            FastAPI app (app/), Dockerfile, requirements
  app/services/   orders.py (pipeline), sync.py (tracking, stock, reconcile), settings_service.py, alerts.py
  app/adapters/   woocommerce.py, telegram.py + mock_supplier.py, mock_store.py
  app/routers/    ui.py (dashboard), webhooks.py, internal.py (n8n), auth.py
  app/templates/  Jinja2 + HTMX pages           app/static/  built CSS + HTMX (no CDN)
n8n/workflows/  six importable workflows (generated by scripts/make_workflows.py)
frontend/       Tailwind build (only needed if you change templates: npm install && npm run build)
scripts/        gen_secrets.py, hash_password.py, backup.sh, restore.sh, make_workflows.py
docs/           setup, deploy, assumptions, testing
tests/          pytest (SQLite by default, real Postgres with TEST_DATABASE_URL)
```

> Note: `api/app/services/{jobs,margin,notify,settings}.py`, `api/app/templates/{_kpis,_macros,logs,product_form}.html` and `api/app/static/app.js` are leftovers from an earlier scaffold in this folder. Nothing in the current app imports them. They can be deleted.


## v2: connect any company, live agents, catalog
- **Connect** page: add suppliers and websites by API key, by describing a REST API, or by dropping a connector file. See `docs/CONNECTORS.md`.
- **Import products** + **Products**: import from a supplier, list on your stores/sites, see counts by supplier and store.
- **Agents** page and dashboard: live view of every agent (updates every 3 s). The Windows runner schedules agents itself (`INTERNAL_SCHEDULER`); on a VPS n8n does it.
- Accent colour is violet (`--accent` in `api/app/static/app.css`).
