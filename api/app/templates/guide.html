1. Ye project kya hai

Cheape Deal ek free, self-hosted dropshipping automation hai. Tum apna store chalate ho, supplier ka maal customer ko seedha bhejwate ho, aur beech ka kaam (order lena, supplier ko dena, tracking, price, stock) ye khud karta hai.

Ye tumhare PC (Windows) par bhi chalta hai aur VPS par 24x7 bhi. Kisi paid service ki zarurat nahi. Tumhara data tumhare apne computer/server par rehta hai.

Dropshipping ka matlab: stock tumhare paas nahi hota. Customer order karta hai, tum supplier se wahi maal customer ke address par bhijwate ho. Fayda = bechne ka price minus supplier ka price.

2. Ek order ka safar

  1. Customer tumhare store par order karta aur paise deta hai. Store ye order Cheape Deal ko bhejta hai (webhook), ya Missed-order sweep agent khud utha leta hai.
  2. Risk check: fake email, adhura address, freight forwarder, bahut bada order... score banta hai. Zyada score = approval mein ruk jata hai.
  3. Margin guard: agar profit minimum margin se kam hai to order ruk jata hai (loss mein nahi bechte).
  4. Bada order ya risky order: Approvals mein tumhari haan ka intezaar.
  5. Order supplier ko jata hai (CJ API se). Rehearsal (DRY-RUN) ON ho to sirf nakli, asli order nahi jata.
  6. Tracking agent supplier se tracking number laata hai, store par note daalta hai, customer ko email (agar ON) bhejta hai.
  7. Delivered hone par order complete. Finance mein uska asli profit dikhta hai.

3. Pehli baar start karna

Windows: project folder mein run_local.bat par double-click karo. Python 3.11+ chahiye (python.org se, "Add to PATH" tick karke). Pehli baar thoda time lagta hai. Terminal mein URL, username aur password dikhega. Browser khud khulega.

Login: terminal mein jo username/password dikha wahi use karo. Password bhool gaye to python scripts\local_run.py --reset-password.

Pehle 10 minute: Website → Website jodo mein CJ key ek baar daalo → Catalog se 1-2 product import karo → Start dabao (Rehearsal mode ON rehta hai, asli order CJ ko nahi jata) → Agents page par dekho kaam ho raha hai.

Dashboard par Setup checklist dikhta hai: ek-ek step jo abhi baaki hai.

5. Agents (robots)

Agent matlab ek chhota robot jo ek kaam baar-baar karta hai. Windows par ye app ke andar chalte hain (n8n nahi chahiye).

  • Router (har 20 sec): naye orders ko check karke supplier ko deta hai.
  • Sweeper (5 min): store mein jo order miss ho gaya use pakadta hai.
  • Tracking (2 min): tracking laata hai, customer ko batata hai.
  • Stock (30 min): supplier ka stock/price check (saare suppliers ek saath), nuksan wala product chhupata hai, backup supplier par switch.
  • Reconciler (6 ghante): store aur supplier ke records match karta hai.
  • Strategist (6 ghante): market price dekh kar price lagata hai.
  • Scout (6 ghante + price watch 12 ghante): eBay prices (price watch).
  • Reporter: roz ki report, backup, heartbeat.

Sab ko ek button se rokne ke liye Pause (kill switch) upar hai.

6. Orders, approval, rehearsal

Rehearsal (DRY-RUN): default ON. Order andar aata hai par supplier ko asli order nahi jata. Jab tak system par bharosa na ho, ON rakho. Settings mein band hota hai.

Approval threshold: is amount ya usse bade order tumhari haan ke bina nahi jate. 0 = band.

Minimum margin: isse kam profit wale order block. Daily order cap bhi hai (ek din mein max kitne order).

Retry: supplier error ho to 2, 4, 8, 16, 32 minute baad dobara. Phir bhi fail = "needs you" mein, Alerts mein dikhega.

Customer tracking page: har order ka ek link /track/<token> hota hai jo customer ko de sakte ho.

7. Strategy: jaha mehenga wahan becho

Example: pankha supplier se $24 ka. US mein shelf price $2000. 25% undercut = $1500. Agent product ko $1500 par lagata hai aur supplier India se ship karta hai. Bich ka kharcha (shipping, duty, VAT, fee) hisaab mein pehle se jud jata hai.

  1. Markets tab mein desh ke shipping/duty/tax numbers apne asli numbers se badlo (seed numbers sirf andaaza hain).
  2. Exchange rate confirm karo (autopilot unconfirmed rate par kaam nahi karta).
  3. Product ke liye us desh ka price daalo (haath se, CSV, ya Price watch se).
  4. Analyse now dabao. Status: viable (faydemand), not viable, needs check (shak wala price), stale (purana), needs rate.
  5. Pehle Suggest only mode mein dekho. Bharosa ho to Autopilot ON karo.

Safety: floor price (isse neeche kabhi nahi), minimum profit %, minimum gap, price kitne din purana chalega, sanity ratio (bahut bada price human check ke liye ruka rehta hai).

CJ Dropshipping connect karna (2 minute)

  1. CJ account → Authorization (API) page → Generate API Key. Key CJxxxx@api@... jaisi dikhti hai.
  2. Cheape Deal → Connect → upar CJ wale box mein key paste karo → "Jodo aur default banao". Koi Authorize nahi, token apne aap renew hota hai.
  3. Orders CJ ke wallet balance se pay hote hain: CJ account mein thoda balance rakho. Pehle Rehearsal (DRY-RUN) ON rakho.

Apni website: Vercel (front) + Render (backend)

Menu → Website page par products ka live preview, order payment, aur deploy ke steps hain. Poora guide: docs/WEBSITE_DEPLOY.md.

Affiliate + Print-on-Demand (30 connectors)

Menu mein Affiliate + POD. Yahan 30 programs commission ke hisaab se rank hain (Digistore24, ClickBank, Zazzle, Cuelinks, CJ Affiliate, Banggood, Flipkart, AliExpress, Amazon, eBay, Awin, Rakuten, impact, Printful, Printify ...).

  • Affiliate: product tumhari website par "Buy at ..." ke saath dikhta hai. Customer us par click kare to hamare tracked link se merchant ke paas jata hai; khareedne par network tumhe commission deta hai. Cart/checkout/stock nahi hota.
  • Feed wale programs: network ke dashboard se product-feed URL copy karo, connector mein paste karo, "Test" hone ke baad Affiliate agent khud products laata hai.
  • Amazon / eBay: API key daalo, live search se products aate hain.
  • Printful / Printify: apne designs unke dashboard mein banao; yahan se import hote hain, order aane par wo print karke ship karte hain.

Sach: commission % program/directory ke bataye hue hain (source link ke saath) aur badalte rehte hain. Hum clicks ginte hain, kamai network dashboard mein dekho. Asli accounts par live test nahi hua.

9. Price watch (eBay)

Strategy page par Price watch panel. Free eBay developer keys (developer.ebay.com) daalo, ON karo. Har product ke Strategy page par "search words" do (jaise "table fan 16 inch").

Har 12 ghante agent eBay US/UK/DE/AU/CA/FR/IT/ES se 5+ listings ka median laata hai (bahut sasta/mehenga kachra hata kar) aur market price bana deta hai.

Dhyan: ye listed (asking) prices hain, bikne wale (sold) nahi. Galat search words = galat price. Isliye pehle Suggest-only mein check karo.

10. Risk, Returns, Finance

Risk check: 0-100 score. Limit (default 60) ya upar = Approvals mein ruka, wajah likhi hoti hai. Blocked country/email list bhi hai.

Returns: order page par "Return kholo". Approve → maal wapas mila → refund likho (customer ko kitna, supplier ne kitna wapas diya). Refund ka asli paisa tum apne payment provider se hi lautate ho. Yahan sirf record aur profit ka hisaab hota hai.

Finance: revenue − refund − product cost (order ke time ka) − shipping − payment fee = net profit, mahine ke hisaab se, aur supplier ke paas phansa paisa. Shipping andaaza hota hai jab tak order page par asli kharcha na daalo. Business details bharo to invoice sahi banta hai.

Invoice: order page → Invoice → Print. Ye simple bill hai. GST/export ke rules CA se pucho.

11. Multi-country

Strategy mein "Multi-country" ON karo (Autopilot bhi ON). Fir jis desh ka apna store connected hai aur wahan profit hai, product wahan us desh ke apne price par lagta hai. Jo desh ab profitable nahi raha, uska price normal par wapas.

Markets tab mein har desh ke saath uska store jodna padta hai.

12. Security: 2FA aur users

2FA: Users page → Set up 2FA. Authenticator app mein key daalo, code confirm karo. Phir login par code lagega. Phone kho jaye to python scripts\local_run.py --disable-2fa.

Roles: admin = sab kuch. operator = roz ka kaam, settings/connect/system/users nahi. viewer = sirf dekhna. 2FA abhi sirf admin account par hai.

Internet par chalate ho to HTTPS (Caddy ya Cloudflare Tunnel) lagao, strong password rakho, 2FA ON karo.

13. System, backup, heartbeat, API

Health checks: System page har cheez ko OK/Check/Problem dikhata hai aur fix batata hai.

Backup: roz apne aap, 7 latest rakhe jate hain. "Back up now" se turant. Restore: app band, backup ko cheapedeal.db par copy, app start.

Heartbeat: healthchecks.io ya UptimeRobot ka free ping URL daalo. App har 5 minute ping karta hai. Server band hua to wo tumhe alert karenge.

Daily report: roz tay ghante par Telegram par (agar set hai). Customer emails: shipped/delivered par email, SMTP chahiye.

Read-only API: X-API-Key header se /api/v1/stats, products, orders, opportunities. Ye kuch badal nahi sakta.

14. VPS par 24x7

Linux VPS par: run_linux.sh chalao ya deploy/cheapedeal.service (systemd) lagao taaki reboot par bhi chale. Host 0.0.0.0, aage HTTPS proxy. Docker + Postgres + n8n ka option bhi hai: DEPLOY.md dekho.

Windows par PC band = agents band. Auto-start ke liye scripts\windows_autostart.bat.

15. Live jaane ka safe checklist

  1. Rehearsal mode mein ek test order dekho.
  2. Asli supplier connect karo, Test connection dabao.
  3. Ek-do asli product import karo, shipping method set karo.
  4. Rehearsal ON rakh kar asli store ka order bhejo, dekho sab sahi jata hai.
  5. Approval threshold chhota rakho (jaise $50) pehle hafte.
  6. Risk check, Finance business details, Heartbeat, 2FA set karo.
  7. Phir sirf ek asli order ke liye rehearsal band karo. Supplier dashboard mein order check karo.
  8. Sab theek ho to dheere dheere cap badhao.

Asli account ke saath pehla test tumhe karna hoga: mere paas tumhare supplier/store ke login nahi hain, isliye real-world connectors tumhare account par hi verify honge.

16. Problem aaye to

Order "pending approval" mein atka: Approvals kholo; wajah likhi hai (bada amount ya risk).

Order supplier ko nahi gaya: Rehearsal ON to nahi? Pause to ON nahi? Alerts dekho.

Strategy "needs rate": Exchange rate confirm nahi. Strategy → Rates.

Price watch kuch nahi laaya: keys, ON switch, search words, aur 5 se kam listings to nahi.

Email nahi ja raha: SMTP_* settings ya email-seller connection mein SMTP.

Login nahi ho raha: 5 galat try = 10 minute block. 2FA code ka phone clock sahi rakho.

Page khula par 403: tumhara role operator/viewer hai, admin se pucho.

17. Shabdkosh

Margin
Profit / selling price.
Landed cost
Product + shipping + duty: customer tak pahunchne ka total kharcha.
MOQ
Seller ka minimum order quantity.
Undercut
Market price se itna kam par bechna.
DRY-RUN
Nakli chalana, asli order nahi.
Webhook
Store ka system ko "naya order aaya" ka signal.
Chargeback
Customer bank se paisa wapas mangta hai.
2FA
Password ke upar phone ka 6-digit code.

18. Sach: kya nahi hai

  • Asli supplier/store connectors ko maine mocked tests se check kiya hai. Tumhare asli account par pehla test tumhe karna hoga.
  • eBay price feed asking price deta hai, sold price nahi. Aur ye sirf eBay se, Amazon se nahi.
  • WhatsApp sirf "chat kholo" link hai, automatic WhatsApp message nahi.
  • UI abhi English + Hinglish mix hai, poora Hindi toggle nahi.
  • AI-based product ya description generation nahi hai.
  • Tax/GST/export compliance ka advice nahi: invoice sirf simple bill hai.
  • Agents tab tak chalte hain jab tak PC/server chalu hai.
